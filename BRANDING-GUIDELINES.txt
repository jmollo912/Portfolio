BRAND OVERVIEW
--------------
Name: Giuseppe Mollo
Site: Personal portfolio (UX/UI + graphic design case studies)
Tone: Clear, confident, approachable. Not corporate jargon. Short sentences. Show craft and process.
Layout: Spacious, Main White backgrounds, white floating icon nav, subtle motion.


TYPOGRAPHY
----------
Body and UI: Inter, with system-ui fallbacks. All paragraphs, nav, case study body, footer. Home page loads Inter as a variable font (Google Fonts, 100–900) so hero letter hover can ease weight smoothly.
Accent / display: Borel (Google Fonts). Use sparingly — e.g. hero caption word "desk".
Hero screen label: Inter on Lottie overlay — "gm" bold + "design" light on monitor mockup.

Type scale (see css/global.css):
- Page / section display titles (Lab “Welcome to The Lab” only): clamp(32px, 3.5vw, 52px), weight 500, letter-spacing -0.03em, line-height 1.05, #000000; wraps below 900px; mobile clamp(28px, 8vw, 36px)
- Index “My Favorite Work” uses `.work-section-heading` — same look as work-card headlines (clamp 18–22px, weight 600, black) but its own CSS class; keeps the thin full-width rule under the label
- Section heading: clamp(28px, 4vw, 42px), weight 700
- Large case titles: about 50px / 48px project titles
- Body / case content: 18px, line-height about 1.65–1.7
- Section label: 12px, uppercase, letter-spacing 0.12em, weight 500 (case-study section labels)
- Case pill: 15px; title weight 700, tag weight 500


COLOR PALETTE
-------------
Use hex values below unless opacity is noted.

Primary text:
- Text primary: #000000 — headings, body, footer, case studies

- Nav inactive: #B8B8B8 — floating nav inactive icons (semi-transparent charcoal assets) + hover label under nav
- Nav active: charcoal square #2B2B2B (--cta) with white icon; label text #B8B8B8 under active item

Backgrounds:
- Page: #FFFFFF
- Subtle sections: #F5F5F5 — footer, some case UI
- Grid / card boxes: #E4E8F2 — work grid cards, case info cards, logo breakdown, Mac photo canvas
- Floating nav: solid #FFFFFF pill (no glass)

Accent / interactive:
- Primary CTA: #2B2B2B (--cta) resting and hover, text #FFFFFF — about-cta-btn (primary), resume-download-btn; hover scales to 1.12 with snappy transform (0.1s, cubic-bezier(0.4, 0, 1, 1) — no ease-out drag); touch: no transform
- Profile card Connect: charcoal pill; hover scale 1.12 + rotate(2deg) like footer CTAs (touch: no transform)
- Profile card: rests tilted; hover straightens (0deg) and scales to 1.05 (touch: no expand)
- Brand blue accent: #4763FF (rgb(71, 99, 255)) — hero animation lines/fill (not primary CTAs or footer pills)
- CTA secondary: white pill, #000000 text (about-cta-btn--secondary, Contact links); hover scales to 1.12 with no rotate
- Footer pill: charcoal #2B2B2B (--cta), text #FFFFFF; hover keeps charcoal (no color change), scale 1.12 + rotate(2deg); email reveals mail icon, social reveals brand icons (same pattern as about CTAs)
- Nav Resume: charcoal pill; hover scale 1.12 + rotate(2deg) with same snappy transform as primary CTAs; download icon reveals — rotate also on footer pills (footer-pill-link) and profile-card Connect
- Pill separator dot: #C7C7C7 (before case pill tag)

Hero only:
- Monitor "gm design" label: #FFFFFF (lottie-label on hero screen)
- Hero welcome text (“Welcome to my portfolio!”): after typing animation, each letter is hoverable — hovered letter Inter weight eases 600 → 900 and scale 1 → 1.25 (0.2s); immediate left/right neighbors ease weight 600 → 750 and scale 1 → 1.12 (0.2s); rest of hero stage stays pointer-events none so wall pics still work

Custom cursor:
- Currently DISABLED (native pointer). Code kept for easy re-enable.
- To turn on: CUSTOM_CURSOR_ENABLED = true in main.js + restore CSS toggle in global.css
- Dot / expanded styles remain in css/global.css when disabled


UI COMPONENTS
-------------
1. Floating navigation — white pill with Home / Work / Lab / About icons (media/NavBar); charcoal (#2B2B2B) rounded square marker slides to active item; white active icon / grey inactive icon; grey Home/Work/The Lab/About label appears under the hovered icon only (hidden otherwise) in a small white rounded box with light shadow; when the hovered icon is the active page, that label box is charcoal with white text. Lab navigates to html/lab.html (same marker handoff as About). Top-left gmdesign.svg wordmark (17px tall, left: 28px) links home; top-right Resume charcoal pill (same as footer Resume — white text, hover keeps charcoal + scale 1.12 / rotate 2deg, download icon reveals). Cross-page (index ↔ lab ↔ about): ?navFrom= handoff slides marker from previous tab. Resume also in mobile menu.
2. Case study cards (home page + case-study “More work”) — square cover image with rounded corners. Homepage: gray eyebrow (“Project · Discipline”) + bold black headline. Case-study “More work” cards: eyebrow only (no headline). Same `.work-card` markup otherwise. No tag chips, no hover scale, no white overlay bar. Corner arrow still appears on hover/focus. Homepage is 2-up; “More work” is 3-up (2-up ≤700px, 1-up ≤420px).
3. Case study section headers — section label at 40% opacity; heading and intro full black.
4. Buttons — rounded about 10px; primary charcoal (#2B2B2B) with white text; hover keeps charcoal and scales to 1.12 (no rotate by default). Secondary white pill with black text, same scale-only hover. Rotate(2deg) on hover for nav Resume, footer-pill-link (footer bar + CBS Learn More Contact), and profile-card Connect.
5. Custom cursor — currently DISABLED (native pointer). Re-enable via CUSTOM_CURSOR_ENABLED in main.js + CSS toggle in global.css.
6. Motion — scroll fade, nav marker; honor reduced-motion in CSS. Floating nav, gm logo, and Resume stay fixed while scrolling.
7. Case-study section navigation — left-side white rounded stack (~17px type). Active text charcoal #2B2B2B, inactive #B8B8B8. Matching-width “Back” is always pinned near the top (including the hero). Section names ride up with Overview, then stick just under Back. Back: grey at rest, charcoal + left arrow reveal + scale 1.12 on hover (no rotate). Case content uses equal side gutters (~168–240px desktop, tighter ≤900px) so the nav stays in the left margin; below 600px gutters drop to 0 and container padding is 12px. Uses scroll spy. Mobile back button, hamburger, mobile dropdown nav, and the desktop floating nav/back group are wrapped in a single `<header class="case-site-header">` landmark (all children keep their existing fixed positioning, so this is a pure a11y/SEO wrapper with no visual change). On phones (<=600px) the full-bleed case hero (`.case-hero-centered`) is hidden so the page opens on Overview. End of each case study: “More work” uses `.work-section-heading`, then the same homepage work cards (eyebrow + headline, square covers, corner arrow, no hover scale) for the other projects — 3-up desktop, 2-up ≤700px, 1-up ≤420px.
8. Lab experiments — intro block on top (title + muted body); below it a two-column workspace with a fixed-width left experiment nav (~15rem) and right media + copy so active nav type size doesn’t change image width. Nav is vertically centered to the media/image frame height (not the full panel with copy). Nav: 17px inactive rgba(0,0,0,0.38); active charcoal #2B2B2B at 20px / weight 600; hover charcoal + scale 1.08 (style only — sections change on click, not hover preview). Each nav link has 12px vertical padding (>=44px tap height) and each panel `<article>` carries a visually-hidden (`sr-only`) `<h2>` matching its nav label, so the page reads h1 → h2 → h3 (footer) with no skipped level. “Building with New AI” is a non-selectable coming-soon item: hover (or tap) shows a charcoal “Coming soon!” tip. Default first section selected on load. Desk Model and Arduino use the same multi-page carousel with in-image prev/next arrows and dots; arrows are 44x44 and dots have a 32x32 invisible tap target around the visible 8px dot (visual size unchanged). Arduino page 3 is a YouTube facade (thumbnail + play) that embeds https://youtu.be/dX4d0BOOTt8 inline on click; leaving the slide/panel resets to the thumbnail.

CONTENT AND SEO
---------------
Language: English (lang="en")
Page titles: {Page} — Giuseppe Mollo
One logical h1 per page; case studies use project title in overview.
Alt text on meaningful images; decorative hero floats may use empty alt.
Every page has viewport, canonical, meta description, and a full Open Graph +
Twitter card set (og:type/title/description/url/image/site_name +
twitter:card=summary_large_image). Domain is https://gmollodesign.com (from
CNAME) — keep og:url/og:image absolute against that domain, and give every
page a distinct og:image (existing cover/hero art, no new assets).
Mobile image budget: on screens <600px, content images should not exceed
~35-40vh unless they're a full-bleed hero (case-hero-main-image, case
heroes) — enforced via vh-capped heights/max-heights on case-content-image,
coral-prototype-img, comparison-image (FlockSports), and
robot-comparison-image (Convoy).
Touch targets: interactive controls target >=44x44px (lab/Convoy carousel
arrows, lab side-nav links, case-hamburger, nav-icon-link). Carousel page
dots (lab-carousel-dot, carousel-indicator) keep their small 8px visible
dot but sit inside a 32x32 invisible button so the tap area is much larger
without changing the look. Hover-only reveals (index work-card title/tag
pill and corner arrow) are always-on below 1199px instead of relying on
:hover, since touch has no reliable hover state.

RULES FOR AI
------------
1. Match this document. If you change colors or fonts in CSS, update this file too (or ask Giuseppe).
2. Do not bring back gray body text (e.g. #6F6F6F) unless this file is updated. Body is #000000.
3. Muted text is only section labels and case pill tags at 40% black, unless this file says otherwise.
4. Nav: icon pill; inactive icons grey, active charcoal square + white icon; label #B8B8B8 only on hover.
5. Keep accessibility: focus outlines, aria-current, semantic HTML, sr-only helpers.
6. Minimize scope — static HTML/CSS/JS; no frameworks unless requested.
