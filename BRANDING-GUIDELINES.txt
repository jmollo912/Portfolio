BRAND OVERVIEW
--------------
Name: Giuseppe Mollo
Site: Personal portfolio (UX/UI + graphic design case studies)
Tone: Clear, confident, approachable. Not corporate jargon. Short sentences. Show craft and process.
Layout: Spacious, Main White backgrounds, white floating icon nav, subtle motion.


TYPOGRAPHY
----------
Body and UI: Inter, with system-ui fallbacks. All paragraphs, nav, case study body, footer.
Accent / display: Borel (Google Fonts). Use sparingly — e.g. hero caption word "desk".
Hero screen label: Inter on Lottie overlay — "gm" bold + "design" light on monitor mockup.

Type scale (see css/global.css):
- Section heading: clamp(28px, 4vw, 42px), weight 700
- Large case titles: about 50px / 48px project titles
- Body / case content: 18px, line-height about 1.65–1.7
- Section label: 12px, uppercase, letter-spacing 0.12em, weight 500
- Case pill: 15px; title weight 700, tag weight 500


COLOR PALETTE
-------------
Use hex values below unless opacity is noted.

Primary text:
- Text primary: #000000 — headings, body, footer, case studies
- Text muted (40%): rgba(0, 0, 0, 0.4) — section labels and case pill tags only
- Nav inactive: #B8B8B8 — floating nav inactive icons (semi-transparent charcoal assets) + hover label under nav
- Nav active: charcoal square #2B2B2B (--cta) with white icon; label text #B8B8B8 under active item

Backgrounds:
- Page: #FFFFFF
- Subtle sections: #F5F5F5 — footer, some case UI
- Grid / card boxes: #E4E8F2 — work grid cards, case info cards, logo breakdown, Mac photo canvas
- Floating nav: solid #FFFFFF pill (no glass)

Accent / interactive:
- Primary CTA: #2B2B2B (--cta) resting and hover, text #FFFFFF — about-cta-btn (primary), profile-card-connect, resume-download-btn; hover scales to 1.12 with snappy transform (0.1s, cubic-bezier(0.4, 0, 1, 1) — no ease-out drag); touch: no transform
- Profile card: rests tilted; hover straightens (0deg) and scales to 1.05 (touch: no expand)
- Brand blue accent: #4763FF (rgb(71, 99, 255)) — hero animation lines/fill (not primary CTAs or footer pills)
- CTA secondary: white pill, #000000 text (about-cta-btn--secondary, Contact links); hover scales to 1.12 with no rotate
- Footer pill: charcoal #2B2B2B (--cta), text #FFFFFF; hover keeps charcoal (no color change), scale 1.12 + rotate(2deg); email reveals mail icon, social reveals brand icons (same pattern as about CTAs)
- Nav Resume: charcoal pill; hover scale 1.12 + rotate(2deg) with same snappy transform as primary CTAs; download icon reveals — rotate also on footer pills (footer-pill-link)
- Pill separator dot: #C7C7C7 (before case pill tag)

Hero only:
- Monitor "gm design" label: #FFFFFF (lottie-label on hero screen)

Custom cursor:
- Currently DISABLED (native pointer). Code kept for easy re-enable.
- To turn on: CUSTOM_CURSOR_ENABLED = true in main.js + restore CSS toggle in global.css
- Dot / expanded styles remain in css/global.css when disabled


UI COMPONENTS
-------------
1. Floating navigation — white pill with Home / Work / Lab / About icons (media/NavBar); charcoal (#2B2B2B) rounded square marker slides to active item; white active icon / grey inactive icon; grey Home/Work/The Lab/About label appears under the hovered icon only (hidden otherwise). Lab is placeholder (not navigable): hover shows grey “The Lab” under the icon plus a charcoal “Coming soon” tip next to the cursor. Top-left gmdesign.svg wordmark (17px tall, left: 28px) links home; top-right Resume charcoal pill (same as footer Resume — white text, hover keeps charcoal + scale 1.12 / rotate 2deg, download icon reveals). Cross-page (index ↔ about): ?navFrom= handoff slides marker from previous tab. Resume also in mobile menu.
2. Case study cards (home page) — white pill bottom-left; project name black; tag at 40% opacity. Hover scale uses footer CTA timing (transform 0.2s ease). Cursor pill shows white text (e.g. "View Project" or custom data-cursor-label).
3. Case study section headers — section label at 40% opacity; heading and intro full black.
4. Buttons — rounded about 10px; primary charcoal (#2B2B2B) with white text; hover keeps charcoal and scales to 1.12 (no rotate by default). Secondary white pill with black text, same scale-only hover. Rotate(2deg) on hover for nav Resume and footer-pill-link (footer bar + CBS Learn More Contact).
5. Custom cursor — currently DISABLED (native pointer). Re-enable via CUSTOM_CURSOR_ENABLED in main.js + CSS toggle in global.css.
6. Motion — scroll fade, nav marker; honor reduced-motion in CSS. Floating nav, gm logo, and Resume stay fixed while scrolling.
7. Case-study section navigation — left-side white rounded stack (~17px type). Active text charcoal #2B2B2B, inactive #B8B8B8. Matching-width “Back” is always pinned near the top (including the hero). Section names ride up with Overview, then stick just under Back. Back: grey at rest, charcoal + left arrow reveal + scale 1.12 on hover (no rotate). Case content uses equal side gutters (~168–240px desktop, tighter ≤900px) so the nav stays in the left margin; below 600px gutters drop to 0 and container padding is 12px. Uses scroll spy.

RULES FOR AI
------------
1. Match this document. If you change colors or fonts in CSS, update this file too (or ask Giuseppe).
2. Do not bring back gray body text (e.g. #6F6F6F) unless this file is updated. Body is #000000.
3. Muted text is only section labels and case pill tags at 40% black, unless this file says otherwise.
4. Nav: icon pill; inactive icons grey, active charcoal square + white icon; label #B8B8B8 only on hover.
5. Keep accessibility: focus outlines, aria-current, semantic HTML, sr-only helpers.
6. Minimize scope — static HTML/CSS/JS; no frameworks unless requested.
